# 字段来源清单（哪些要 OCR / 导入 / 识别）

> 回答两个问题：
> 1. 每个字段**从哪份文件**来；
> 2. 该字段**怎么抓**（直接读 Excel / 关键词抽取 / OCR）。
>
> 来源分三类：
> - 🟢 **结构化表格**（Excel/CSV）→ 直接 `pandas.read_excel` 读单元格，无需识别
> - 🟡 **Word 正文/表格**（合同、制度）→ 关键词定位 + 正则 / LLM 语义抽取
> - 🔴 **纸质/扫描件**（签章页、签证单、纪要、手写日志）→ OCR + 版面分析（PaddleOCR / LayoutLMv3）

## 三、抓取流程（导入链路）

```
文件落地 → 按格式分流
   ├─ Excel   → pandas 直读 → 🟢 字段落库
   ├─ Word    → python-docx 读正文+表格 → 关键词/正则/LLM 抽取 → 🟡 字段落库
   └─ PDF/图片 → PaddleOCR 文字识别 + LayoutLMv3 版面分析
                 → 结构化抽取 → 🔴 字段落库
                     ↓
            统一数据模型（中间表，见《统一数据模型定义》）
                     ↓
        规则引擎（Python 确定性硬算）→ 命中规则 → 生成疑点
```

## 四、给"规则引擎"的字段缺口提示

| 规则 | 需要字段 | 当前 A 项目数据是否够 |
| --- | --- | --- |
| 规则一（结算超合同 5%）| 合同价 + 审定金额 + 三重一大决策 + 补充协议 | 合同价/审定金额有；**决策纪要、补充协议缺**（需 OCR 补）|
| 规则二（禁止签证却签证）| 合同禁止签证标志 + 结算签证项 | ✅ 齐（主体/土方合同都写"无签证"，土方结算有 SDQ-QZ-001）|
| 规则三（材料超耗未扣）| 损耗率 + 预算量/领用量 + 结算扣款项 | ✅ 齐（物资台账有超耗，结算"扣款及罚款"栏为空=未扣）|

| 规则五（同区同类价格低 15%）| 三份同类合同清单单价 | ⚠️ 需横向合同数据（A 项目仅 4 份不同专业合同）|
| 规则六（清单外项）| 结算清单项 vs 合同清单项 vs 业主清单项 | ✅ 齐（土方"清淤泥"不在合同清单、不在业主结算）|
