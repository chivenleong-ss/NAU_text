## 一、分供方结算管理办法（FG，60 条）

- **FG-001**（阈值·时限）收到图纸后 1 个月内完成图纸计量并建立实物工程量控制台账，经三级总经济师审批，一经审批不得随意更改 → 超期/未审批预警。出处 3.1。
- **FG-002**（阈值）分供方工程量不得大于 min(业主结算量, 竣工图量)，须"三算对比"（收支口径一致）→ 超量核减。出处 3.3。
- **FG-003**（禁止）结算须严格执行分供方合同，严禁随意调整 → 拦截。出处 3.4。
- **FG-004**（流程）结算额超合同额或内容范围增减，须按局招采管理部规定办理 → 退回。出处 3.5。
- **FG-005**（阈值·时限）月度结算期为上月 21 日至本月 20 日 → 不符预警。出处 4.1。
- **FG-006**（禁止）当月内容月结月清，不得预留/超结工程量 → 拦截/核减。出处 4.2.1。
- **FG-007**（阈值）按业主结算价收管理费的，按业主审定造价与实际完成造价取小值结算 → 核减。出处 4.2.2。
- **FG-008**（流程）各类扣款（代工/甩项/资料质量/安全环保/材料调拨/水电住宿/总包管理配合费）须书面告知分供方并签字确认，报商务岗 → 缺签字退回。出处 4.3.1–4.3.6。
- **FG-009**（流程）每月编制月度结算书前，项目经理组织扣款会议集中确认 → 无会议记录预警。出处 4.3.7。
- **FG-010**（禁止）严禁超合同代买代购；扣款及违约责任罚款须月结月清 → 拦截。出处 4.3.8。
- **FG-011**（流程）每月 20 日分供方申请，须签字（有授权委托书）+盖章 → 缺退回。出处 4.4.1。
- **FG-012**（流程·时限）每月 20 日完成形象进度确认；扣款证据经建造总监审核、项目经理审批 → 缺退回。出处 4.4.2。
- **FG-013**（阈值·时限）劳务/专业/服务分包月度结算书每月 23 日前完成报三级商务合约部 → 超期预警。出处 4.4.3。
- **FG-014**（阈值·时限）物资/设备月度结算书每月 23 日前完成报三级履约管理部 → 超期预警。出处 4.4.3。
- **FG-015**（流程）租赁设备首次月度结算需附进场验收合格证明+备案资料 → 缺退回。出处 4.4.3。
- **FG-016**（阈值·时限+流程）劳务/专业分包月度结算三级商务合约部审核、总经济师审批，每月 28 日前完成 → 超期预警。出处 4.4.4。
- **FG-017**（阈值·时限+流程）物资/设备月度结算三级履约管理部审核、执行总经理(履约)审批，每月 28 日前完成 → 超期预警。出处 4.4.4。
- **FG-018**（流程）审批完成后的会签单方可作为月度支付依据 → 未审批即支付拦截。出处 4.4.4。
- **FG-019**（禁止）结算前必须办理完工验收及收方，严禁虚假验工计价 → 拦截。出处 5.1。
- **FG-020**（流程）完工结算前提：合同工作内容已完工、专项验收通过且质量合格 → 未达条件拦截。出处 5.2.1。
- **FG-021**（阈值·时限）满足结算条件后 1 个月内完成完工结算 → 超期预警。出处 5.3.1。
- **FG-022**（阈值·时限）局内部分包在业主结算完成后 1 个月内完成完工结算 → 超期预警。出处 5.3.2。
- **FG-023**（阈值·时限）分供方中途退场后 1 个月内完成退场结算；超合同事项一事一议 → 超期预警/退回。出处 5.3.4。
- **FG-024**（阈值·时限）三级单位在项目部提交完工结算书后 1 个月完成审核审批 → 超期预警。出处 5.3.5。
- **FG-025**（禁止）扣款及违约责任罚款须在完工结算时核实扣除，不得遗漏 → 核减/拦截。出处 5.5.3。
- **FG-026**（流程）完工结算须收支对比、目标成本/收入/结算量价三算对比 → 无对比预警。出处 5.5.4.1。
- **FG-027**（流程）完工结算超目标成本但未亏损，项目部自查并书面报告 → 预警。出处 5.5.4.2。
- **FG-028**（流程）发包不亏损、完工结算超目标成本且亏损，商务合约部联合纪检督查 → 预警/违规。出处 5.5.4.2。
- **FG-029**（流程）完工结算书经分包方签字盖章、项目经理签署意见后报三级审核 → 缺签字退回。出处 5.5.5。
- **FG-030**（阈值·时限）收到整改意见后 3 个工作日内整改及补充说明 → 超期预警。出处 5.5.6。
- **FG-031**（流程）三级审核完工结算：劳务专业类财务/履约/安全会商+总经济师/执行总经理审核；物资设备类另加商务合约部校核 → 缺环节预警。出处 5.5.6。
- **FG-032**（流程）完工结算由三级总经理审批；审批后方可作为最终支付唯一凭证 → 未审批拦截。出处 5.5.7。
- **FG-033**（流程·数量）完工结算书一式四份，项目/三级商务/三级财务/分供方各持一份 → 不符预警。出处 5.5.8。
- **FG-034**（流程）图纸做法与招标清单不一致，供应链中心牵头、总经理审批后重定价格 → 未审批退回。出处 5.6.1。
- **FG-035**（流程）计算规则争议：执行合同约定；无约定由供应链/商务/项目协商、总经理审批 → 退回。出处 5.6.2。
- **FG-036**（流程）局内结算争议二级层面无法达成，可向局商务管理部申请 → 预警。出处 5.6.4。
- **FG-037**（阈值·时限）争议收到申报起 30 工作日内解决，书面确定金额并双方签字盖章 → 超期/无签预警。出处 5.6.5。
- **FG-038**（阈值·比例）二级单位抽审比例不得低于 15% → 低于预警。出处 6.1。
- **FG-039**（流程·时限）三级每月 28 日前报结算资料供抽审；抽审前严禁在完工结算书上签字用印 → 超期预警/提前用印拦截。出处 6.1。
- **FG-040**（阈值·时限）二级单位收到资料 2 工作日内决定是否抽审并反馈清单 → 超期预警。出处 6.1。
- **FG-041**（阈值·时限）二级单位原则上 10 工作日内反馈抽审书面结果 → 超期预警。出处 6.1。
- **FG-042**（阈值）被抽审的以二级抽审后造价为最终额；未被抽审的以三级审核后造价为准 → 口径错拦截。出处 6.2。
- **FG-043**（禁止）抽审发现超结超付/应扣未扣，督促退还；拒不退还追回并纳入黑名单 → 核减/违规。出处 6.2。
- **FG-044**（禁止）原则上不允许合同外签证、不得签补充协议 → 预警/违规。出处 7 总起。
- **FG-045**（阈值·时限）签证应在指令内容完成后 30 工作日内办结，月结月清 → 超期预警。出处 7.1。
- **FG-046**（流程）签证遵循"先审批后使用、谁使用谁签字、谁签字谁负责""实事求是、量入而签" → 未先审批拦截。出处 7.2.1。
- **FG-047**（禁止）分供方合同范围内严禁零星用工/材料/机械 → 拦截/核减。出处 7.2.2。
- **FG-048**（禁止）严禁拆分单个签证索赔规避三级审批 → 拦截/违规。出处 7.2.3。
- **FG-049**（流程）变更签证原则上施工前与分供方洽商定单价/包干价；无法施工前定的须总经理审批 → 拦截/退回。出处 7.3.1。
- **FG-050**（流程）合同外签证无单价的，报供应链中心审核、总经济师/总经理审批后方为结算依据 → 缺审批退回。出处 7.3.1。
- **FG-051**（流程）工程指令单由现场工程师编写、建造总监+商务总监审核、项目经理审批后签发 → 缺退回。出处 7.4.1。
- **FG-052**（流程）现场收方由分供方授权人+现场工程师+商务总监+建造经理共同收方、留影像 → 缺退回。出处 7.4.2。
- **FG-053**（禁止）签证审批完成前严禁将有我方签字的签证单提供给分供方 → 拦截。出处 7.4.4。
- **FG-054**（流程）项目签证由三级总经理审批 → 缺审批拦截。出处 7.4.5。
- **FG-055**（流程）签证审批完成后方可并入当月月度结算 → 未审批拦截。出处 7.5。
- **FG-056**（流程）月度结算会签单甲方所有人员签字完成后生效，否则自始无效 → 未全签拦截。出处 附表1.1。
- **FG-057**（流程）完工结算协议书甲方所有人员签字完成后生效，否则自始无效 → 未全签拦截。出处 附表2.1。
- **FG-058**（流程）工程指令单甲方所有人员签字完成后生效，否则自始无效 → 未全签拦截。出处 附表3.1。
- **FG-059**（流程）签证单甲方授权范围内所有人员签字完成后生效，否则自始无效 → 未全签拦截。出处 附表3.2。
- **FG-060**（阈值·时限）内部结算争议：协商期内 10 工作日完成举证；各方 10 工作日内执行决定 → 超期预警。出处 附表4.2。

## 二、总包结算管理办法（ZB，44 条）

- **ZB-001**（阈值·时限）"6116"：竣工前 6 个月启动策划 / 竣工前 1 个月锁定成本 / 竣工后 1 个月报送 / 报出后 6 个月定案 → 超期预警。出处 1.4.1。
- **ZB-002**（阈值·时限）久竣未结：竣工/完成合同/停工撤场之日起 2 年以上未定案未确定最终收入 → 标记违规。出处 2 表1-1。
- **ZB-003**（阈值·比例）施工图预算、竣工结算书集中评审率 100% → 未达拦截。出处 3.3.1.2。
- **ZB-004**（禁止）自施内容总包结算未办结前，项目经理原则上不得兼任他项目（总经理审批除外）→ 拦截。出处 3.4.1.3。
- **ZB-005**（禁止）自施内容总包结算未办结前，商务总监原则上不得兼任他项目（总经理审批除外）→ 拦截。出处 3.4.2.4。
- **ZB-006**（阈值·时限）中标后图纸齐全前提下 2 个月内完成施工图预算编制评审 → 超期预警。出处 4.4。
- **ZB-007**（流程）标准版施工图预算由三级商务合约部集中评审（局级/公司级重点项目二级牵头）→ 未评审退回。出处 4.7.1。
- **ZB-008**（流程）外报版施工图预算经三级商务合约部+总经济师审核、总经理审批后报送 → 缺退回。出处 4.7.3。
- **ZB-009**（流程·时限）进度款申报前 7 天，建造总监确认形象进度、商务总监编报量、项目经理审批 → 未按期/未审批退回。出处 5.1.1。
- **ZB-010**（阈值·比例）过程结算率不低于 10% → 低于预警。出处 5.2.1。
- **ZB-011**（流程）过程结算的策划和结算书报商务合约部评审后方可报送 → 未评审退回。出处 5.2.2。
- **ZB-012**（阈值·时限）签证事件发生后 14 天内（或合同约定）提出签证单 → 超期预警。出处 6.1.1。
- **ZB-013**（阈值·金额+流程）签证单 <200 万项目经理审批；≥200 万三级商务合约部审核+总经济师审批 → 越权/缺审退回。出处 6.1.2。
- **ZB-014**（阈值·时限）索赔事件发生后 14 天内报送索赔意向，持续事件每隔 14 天续报 → 超期预警。出处 6.2.2。
- **ZB-015**（阈值·金额+流程）索赔报告 <200 万项目经理审批；≥200 万三级商务合约部审核+总经济师审批 → 越权退回。出处 6.2.3。
- **ZB-016**（阈值·时限+流程）竣工前 6 个月签《项目总包结算目标责任书》；结算效益率≥目标效益率；经三级商务/总经济师审核、总经理审批 → 越权/超期/低于目标拦截。出处 7.1.2。
- **ZB-017**（阈值·时限）竣工前 6 个月召开结算启动会、编制结算策划 → 超期预警。出处 7.3。
- **ZB-018**（阈值·时限）结算策划书竣工前 6 个月开始编、20 天内完成 → 超期预警。出处 7.3.1。
- **ZB-019**（流程）结算策划书审批：一般项目三级总经济师审批+二级商务管理部备案；重大异常项目二级总经济师审批+局备案 → 缺退回。出处 7.3.3。
- **ZB-020**（流程）结算策划调整报三级商务合约部备案（重大项目报二级）→ 未备案违规。出处 7.3.5。
- **ZB-021**（阈值·时限）总包结算书竣工前 6 个月启动编制 → 超期预警。出处 7.4。
- **ZB-022**（流程）结算书初稿项目部初审后，三级商务合约部组织履约/技术/财务集中评审 → 未经评审不得定稿。出处 7.5。
- **ZB-023**（阈值·时限）结算书竣工后 30 天内（或合同约定）报送 → 超期预警。出处 7.6.1。
- **ZB-024**（流程）竣工结算资料用印报出前须三级商务合约部+总经济师审核、总经理审批；用印前完成成本盘点 → 缺拦截。出处 7.6.2。
- **ZB-025**（流程）报送的结算资料须有权签收人签收并留记录 → 无签收违规。出处 7.6.3。
